hwplayer — 海王音乐播放器（银河麒麟适配版）0.1.0-4
================================================================
目标平台: 银河麒麟 V10 SP1 (x86_64, glibc 2.31, 风华显卡/OpenGL)
上游项目: https://github.com/744733778/Haiwang-Music-Player
构建环境: Ubuntu 20.04 (glibc 2.31) + Rust stable
主程序最高 GLIBC 需求: 2.30  (<= 2.31，兼容)


本次更新（0.1.0-4）
----------------------------------------------------------------
1. 修复「一首播完不会自动播下一首」
   原因：mpv 配了 keep-open=no，播完会卸载文件并进入 idle，
   eof-reached 属性随之失效，界面永远收不到“播完了”，也就不会切歌。
   现在改为 keep-open=yes，并以“进度到结尾 + mpv 自动暂停”判定结束，
   加每曲只触发一次 + 600ms 保护窗，按列表顺序循环播放。
   实测：3 首 10 秒音频，34 秒内严格 01→02→03→01，每首播满，无跳歌。

2. 程序更名为 hwplayer（命令 / 菜单 / 窗口标题 / 包名）
   旧配置仍会被沿用，已导入的音乐文件夹和音量不会丢。

3. 修掉 AppImage 三个会导致真实桌面起不来的打包问题
   （AppRun 软链覆盖二进制、AppRun 未设 LD_LIBRARY_PATH、
    linuxdeploy 跳过 libasound/libjack/libusb）

先校验完整性
----------------------------------------------------------------
  sha256sum -c SHA256SUMS

如果压缩包是在 Windows 上解压、再拷贝到麒麟：
  Windows 不保存 Linux 可执行权限，AppImage 会变成 644，先补一下：
     chmod +x hwplayer-x86_64.AppImage hwplayer-linux-x86_64.elf
  deb 不需要可执行权限。


方式一：deb 安装（推荐，离线可用）
----------------------------------------------------------------
  # 若装过旧版（haiwang-music），两个包互斥，先卸掉
  sudo dpkg -r haiwang-music

  sudo dpkg -i hwplayer_0.1.0-4_amd64.deb

  运行:  菜单里选「hwplayer」，或命令行 hwplayer
  卸载:  sudo dpkg -r hwplayer
  彻底清除: sudo dpkg -P hwplayer

  安装位置:
    /opt/hwplayer/bin/hwplayer       真身
    /opt/hwplayer/lib/               私有运行时库（282 个，含 libmpv+ffmpeg）
    /opt/hwplayer/usr/share/fonts/   文泉驿中文字体
    /usr/bin/hwplayer                启动器（设库路径后 exec 真身）

  离线可用：Depends 只需 libc6 / libgcc / 显卡驱动栈
  （libgl1 libegl1 libdrm2 libgbm1，桌面机自带）。


方式二：AppImage（免安装，可放 U 盘）
----------------------------------------------------------------
  chmod +x hwplayer-x86_64.AppImage
  ./hwplayer-x86_64.AppImage

  若提示缺 FUSE:
    ./hwplayer-x86_64.AppImage --appimage-extract
    ./squashfs-root/AppRun


选择文件夹
----------------------------------------------------------------
  点「浏览…」会调用系统原生文件对话框，依次尝试:
      zenity (GTK) -> kdialog (KDE/UKUI) -> yad -> qarma
  麒麟上想用原生对话框（可选，不装也能用）:
      sudo apt install zenity
  都没有时自动打开内置目录浏览器，功能不受影响。
  输入框支持 ~ 展开、带引号路径、file:// URI，回车即导入。


源码
----------------------------------------------------------------
  source/ 是本次改动后的完整 crate（Cargo.toml + Cargo.lock + src/），
  与交付二进制完全对应，可直接编译:
      cd source && cargo build --release
  需要 Rust stable（上游 Cargo.toml 写的 rust-version=1.82 已失真，
  实际依赖链要求 >=1.89 的 edition2024 支持）与其他系统依赖，
  详见 README.md 的「复现构建」。

  hwplayer-0.1.0-4.patch 是相对上游的 unified diff，可:
      git apply hwplayer-0.1.0-4.patch
  改动文件: src/app.rs, src/mpv.rs, src/main.rs, src/config.rs,
            src/lyrics_online/amll.rs


常见问题
----------------------------------------------------------------
  1) 启动报 OpenGL / EGL 错误
     显卡驱动未就绪。检查: glxinfo | grep "OpenGL renderer"
     风华显卡需装官方驱动或 Mesa。切勿用本包覆盖系统 libGL/libEGL。

  2) 界面中文显示方块
     deb 已内置文泉驿字体；AppImage 通过 APPDIR 兜底加载。
     若仍异常: sudo apt install fonts-wqy-zenhei

  3) dpkg -i 报依赖缺失 libgl1/libegl1/libdrm2/libgbm1
     说明是精简系统、没装显卡 GL 栈，这类机器本来也渲染不了界面。
     先装显卡驱动，或改用 AppImage。

  4) 更多排障见 run-on-kylin.md
