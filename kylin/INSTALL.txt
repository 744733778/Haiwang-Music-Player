本次更新（0.1.0-5）：真正修复「一首播完不会自动播下一首」
----------------------------------------------------------------
0.1.0-4 在构建容器里测试通过，但实机仍然不生效。用 ctypes 直接驱动
libmpv 0.32 做对照实测，定位到两层根因：

1. 0.1.0-4 设了 keep-open=yes。mpv 在这个模式下会把文件挂在末尾并暂停，
   MPV_EVENT_END_FILE 事件永远不发（mpv 的设计，所有版本皆然）——
   事件泵这条最可靠的路径被彻底屏蔽。
2. 于是只剩「进度 >= 时长-0.2 秒 且 pause=1」这一个判据。它同时依赖
   duration 可读、time-pos 贴着时长（容差仅 0.2 秒）、pause 为 true。
   真实声卡有缓冲、不同格式末帧位置不同、pause 也可能保持 0，
   任一条件不成立就永远卡在最后一首。容器测试恰好三个条件都擦边
   满足（wav 差 0.16s、mp3 差 0.19s、flac 差 0.18s），所以被误判为已修复。

修复：
  * 改回 keep-open=no：EOF 时 mpv 卸载文件并发出且仅发出一次
    MPV_EVENT_END_FILE(reason=EOF)，跨 libmpv 版本 / 音频后端 / 音频格式
    都可靠，与 duration、time-pos、pause 全部解耦。
  * poll_mpv() 以该事件为主判据；eof-reached 属性与放宽到 1 秒容差的
    进度判据仅作兜底。
  * 保留每曲只切一次标志与 500ms 切歌保护窗；窗口内到达的事件直接丢弃
    而不缓存，并要求本曲至少播放 700ms —— 避免坏文件 / 无声卡等「瞬间
    EOF」把整个列表连锁跳光。
  * HWPLAYER_DEBUG=1 会打印 eof / ev_ended 与 [pump] END_FILE reason=、
    [advance]，便于实机抓日志排障。

验证（focal 容器 Xvfb + 真实程序，wav/mp3/flac 各 3 秒）：
  * 实时时钟：13 秒内 4 次切歌，严格 01→02→03→01，每首播满 3 秒，
    4 次 END_FILE 与 4 次 advance 一一对应。
  * ALSA 假设备（瞬间 EOF）：1 次 END_FILE、0 次切歌，不再连锁跳歌。

安装（离线，无需联网）
----------------------------------------------------------------
deb（推荐）：
  sudo dpkg -i hwplayer_0.1.0-5_amd64.deb
  菜单里会出现「hwplayer」，或命令行执行 /usr/bin/hwplayer
  升级前请先卸旧包：sudo dpkg -r haiwang-music  (本包 Conflicts/Replaces)
  卸载：sudo dpkg -r hwplayer ；彻底清除：sudo dpkg -P hwplayer

AppImage：
  chmod +x hwplayer-x86_64.AppImage        # Windows 解压 ZIP 会丢执行权限
  ./hwplayer-x86_64.AppImage

注意：deb 与 AppImage 都把 libmpv + ffmpeg 解码链、X11/字体等运行时库
内置在包内，/usr/lib、/lib、/etc/ld.so.conf 一律不写入，离线机可直接安装。
libGL/libEGL 由目标机显卡驱动提供，需在图形桌面会话中运行。

排障：若自动续播仍有异常
----------------------------------------------------------------
  HWPLAYER_DEBUG=1 /usr/bin/hwplayer 2> ~/hwplayer.log
  （AppImage：HWPLAYER_DEBUG=1 ./hwplayer-x86_64.AppImage 2> ~/hwplayer.log）

  日志含义：
    [pump] END_FILE reason=0   mpv 已正常报告「这首歌播完了」
    [advance] from=N song=...  界面已切到下一首
    [poll] pos/dur/paused/eof  每 40 帧采样的播放状态

  若只有 END_FILE 没有 advance，说明切歌保护窗/时长门槛拦住了；
  若两者都没有，说明 mpv 没报告结束（音频设备或文件本身问题）。
  把 hwplayer.log 发回即可定位。
