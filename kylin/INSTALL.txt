hwplayer — 海王音乐播放器（银河麒麟适配版）0.1.0-6
================================================================
目标平台: 银河麒麟 V10 SP1 (x86_64, glibc 2.31, 风华显卡/OpenGL)
上游项目: https://github.com/744733778/Haiwang-Music-Player
构建环境: Ubuntu 20.04 (glibc 2.31) + Rust stable
主程序最高 GLIBC 需求: 2.30  (<= 2.31，兼容)
程序名称: hwplayer（命令 / 包名 / 菜单 / 窗口标题）

本次更新（0.1.0-6）
----------------------------------------------------------------
一、等响度：移植上游 BYD-AplayerFoliaMix「等响度安全增益」
    我们 0.1.0-5 的实现和上游修复前一样，存在同一个 bug：

    * 默认允许正向放大（最高 +20dB）。安静的歌被硬抬到目标响度，
      底噪同步抬高，再叠加下游增益顶到 0dBFS 削波，听感「沙沙」。
    * 峰值缺失时被当成「可以放大」的许可。
    * 更隐蔽的一点：峰值取自单声道下混，左右反相会互相抵消，
      peak 被严重低估，1/peak 的峰值保护形同虚设。

    修复后：
    * 默认只衰减不放大，整体封顶 -1 dBFS（10^(-1/20)≈0.891），
      给 EQ / 淡入淡出 / 系统混音留余量。
    * 峰值有效时再取 min(上限, 1/peak)；峰值缺失时最多到 0dBFS。
    * 设置里新增「允许正向放大」，默认关闭；想要完整 ReplayGain
      对齐（安静歌抬到目标响度）时才勾选。
    * 峰值改为按每个声道取绝对值最大；缓存版本升到 ver=2，
      旧测量结果自动重测。

    实测（真实 libmpv 解码 6 秒 440Hz）：
      安静文件 幅度0.05 -> 需要 +11.07dB，默认施加 -1.0dB
      响亮文件 幅度0.90 -> 需要 -14.04dB，默认施加 -14.04dB
      勾选「允许正向放大」后，安静文件按 +11.07dB 施加。

二、全局热键：移植上游 txt-reader 的 Linux 实现
    方案：global-hotkey 0.6，X11 下用 XGrabKey 注册，不需要 root，
          不需要常驻守护进程，不新增 ELF 依赖（x11-dl 运行时 dlopen）。

      ↑  音量 +（默认每次 5%，设置里可调 1~20）
      ↓  音量 -
      ←  上一首
      →  下一首

    * 窗口最小化/其他程序在前台时同样有效。
    * 切歌去抖 220ms、音量去抖 45ms，按住方向键不会连跳十几首。
    * 输入框聚焦时方向键自动让路，改路径不会误切歌。
    * 音量改动攒 800ms 再写配置，避免按住 ↑ 时狂写磁盘。

    注意：无修饰键的方向键一旦被 grab，运行期间会被本程序独占，
          其他程序收不到方向键（已在 Xvfb + xev 下验证）。不需要时到
          「设置 -> 全局热键」取消勾选，之后只在窗口内生效。
          Wayland 会话拿不到全局 grab，会自动退回窗口内方向键，
          设置里会显示具体原因。

安装（离线，无需联网）
----------------------------------------------------------------
deb（推荐）：
  sudo dpkg -i hwplayer_0.1.0-6_amd64.deb
  菜单里会出现「hwplayer」，或命令行执行 /usr/bin/hwplayer
  升级前请先卸旧包：sudo dpkg -r haiwang-music  (本包 Conflicts/Replaces)
  卸载：sudo dpkg -r hwplayer ；彻底清除：sudo dpkg -P hwplayer

AppImage：
  chmod +x hwplayer-x86_64.AppImage        # Windows 解压 ZIP 会丢执行权限
  ./hwplayer-x86_64.AppImage

注意：deb 与 AppImage 都把 libmpv + ffmpeg 解码链、X11/字体等运行时库
内置在包内，/usr/lib、/lib、/etc/ld.so.conf 一律不写入，离线机可直接安装。
libGL/libEGL 由目标机显卡驱动提供，需在图形桌面会话中运行。

快捷键
----------------------------------------------------------------
  ↑/↓  音量 +/-        ←/→  上一首 / 下一首（默认全局，可在设置里关闭）

排障：想确认热键/续播/增益状态
----------------------------------------------------------------
  HWPLAYER_DEBUG=1 /usr/bin/hwplayer 2> ~/hwplayer.log

  日志含义：
    [hotkey] 已启用（...）       全局热键注册成功
    [hotkey] grab fired: Xxx     X11 抓到了键（即使在别的窗口上）
    [hotkey] action=Xxx ...      界面已执行该动作（被去抖/输入框拦下时不会有）
    [switch] idx=N song=...      已切到第 N 首
    [pump] END_FILE reason=0     mpv 正常报告「这首播完了」
    [advance] from=N song=...    播完后自动切歌
    [gain] 文件 -> Some(-1.0) dB 等响度实际施加的增益
    [poll] pos/dur/paused/eof    每 40 帧采样的播放状态

  把 hwplayer.log 发回即可定位。

已知限制
----------------------------------------------------------------
  * 全局热键依赖 X11；Wayland 会话只能窗口内使用。
  * 主窗口关闭即退出，全局热键随进程释放，不会残留。
