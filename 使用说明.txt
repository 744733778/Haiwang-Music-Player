Rust Music — libmpv + egui 最小播放器（Windows 64 位，Win7 及以上）
版本：2026-10-31 v4
本次更新：① 桌面歌词窗改 Win32 分层窗口（真透明 + 系统级拖动）
          ② libmpv-2.dll 换成自编译精简版：117 MB → 5.7 MB
          ③ 新增等响度（ReplayGain）

文件：
  rust-music.exe    主程序（6.1 MB）
  libmpv-2.dll      播放引擎（5.7 MB，必须与 exe 放在同一目录，缺了会提示“未加载 libmpv”）
  整个文件夹约 12 MB，解压即用，不需要安装。

第一次使用：
1. 两个文件放同一文件夹，双击 rust-music.exe。
2. 顶部「音乐文件夹」输入路径 → 点「导入」；或点「浏览…」选文件夹。
   选完之后程序会记住，**下次启动自动重新扫描**（新增/删除的歌会自动更新），
   不想自动扫就在 ⚙ 设置 里取消勾选「启动时自动重新扫描文件夹」。
3. 左侧点歌开始播放。⏮ ⏯ ⏭、拖进度条跳转、右侧滑条调音量。

关于这个精简版 libmpv（这次换的）：
  · 只保留音频播放需要的东西：ffmpeg 只编进了 mp3 / flac / aac(m4a) / alac /
    ape / wavpack / vorbis / opus / dsd(dsf,dff) / wav 这些音频解码器，
    以及 mp3/flac/ogg/wav/aiff/caf/mov/matroska/asf/ape/dsf/wv/tta 这些封装。
  · 去掉了 OpenGL / Vulkan / D3D11 / libplacebo / 字幕渲染外的重型依赖，
    去掉了网络协议（本程序只用本地文件），所以体积从 117 MB 降到 5.7 MB。
  · 副作用：这个 DLL **不能播视频**（本程序是纯音乐播放器，用不到）；
    也**不支持网络串流**（程序只从本地文件夹读歌）。
  · 仍然是 Win7 兼容的（只依赖 msvcrt.dll 和系统 DLL，无额外运行库）。

桌面歌词窗：
  主界面点「桌面歌词」→ 弹出置顶歌词窗。
  · **真透明**：歌词窗不再依赖 OpenGL 的透明通道，改成 Windows 分层窗口
    （UpdateLayeredWindow）+ 自己逐像素画，所以远程桌面 / 云电脑 / 虚拟显卡下
    也是透明，不会再有黑底。
  · **拖动跟手**：在歌词窗上按住直接拖，走的是系统自带的窗口拖动循环，
    鼠标怎么动窗口怎么动，没有延迟也不抖。
  · 位置、大小、字号、颜色都会记住，下次启动原样出现。
  · 点歌词窗上的 🔒（或主界面「锁定歌词」）→ 鼠标穿透，完全不挡操作。
  · 背景不透明度：默认 0%（纯文字浮在桌面），在 ⚙ 设置 里可调 0–100%。
    就算调到 0% 也还能拖——程序给背景留了 1/255 的 alpha，不然分层窗口
    那块区域会“点不到”。

  ⚠ 升级提示：上一版保存的「背景不透明度」会被自动重置为 0（那时候还是黑底），
    如果你之前设过就别奇怪，重新拖一下滑条即可。

等响度（ReplayGain）：
  在 ⚙ 设置 → 「等响度」里勾「启用等响度」。作用是把整个曲库的响度拉齐，
  随机播放时不会一首震耳一首听不清。
  · 算法（移植自 BYD-AplayerFoliaMix 的 LoudnessAnalyzer）：
    解码成 PCM → K 加权（38Hz 高通 + 1.5kHz +4dB 高架）→ 按 400ms 窗口算 RMS
    → 取 95 分位当整曲代表响度 → 增益 = 目标响度 − 实测，夹在 ±20dB。
  · 优先用文件里已有的 ReplayGain 标签；没有就本地测量（可关）。
  · 「扫描全库响度」：只测没测过的，边测边存（loudness.json），随时关掉下次接着测。
    一首歌默认最多解码 90 秒来测，够代表整曲，也够快。
  · 峰值保护：用测到的峰值把增益压到不削波（等价于 min(增益, 1/峰值)）。
  · 目标响度默认 −18 dBFS，预增益、缺省增益、专辑增益模式都可以在设置里调。
  · 播放页会显示当前曲目实际施加的增益，比如「响度 +3.2 dB」。

下载歌词：
  · 单曲：播放页「下载歌词」
  · 批量：顶部「批量下载歌词」（自动跳过已有 .lrc 的歌）
  依次尝试 4 个源：AMLL 逐字库 → QQ 音乐 → 网易云 → 酷狗（顺序可在设置里调）。
  任何一源命中高置信度就直接用，否则取全部源里分数最高的。≥60 分才写入。
  写入音频同目录的 <文件名>.lrc（统一成增强逐字格式）；有翻译时另存 .tlyric.lrc。
  逐字（卡拉OK）：AMLL / QQ / 酷狗 提供逐字，网易云一般只有整行。

其它设置：字号 16–72px、已唱/未唱/翻译三色、歌词窗宽高、显示翻译/下一句、
         歌词源顺序（↑↓）、启动自动重扫。

说明 / 限制：
- 支持 Windows 7 / 10 / 11（64 位）。本版按 Win7 兼容方式重编了标准库，
  不导入 GetSystemTimePreciseAsFileTime / WaitOnAddress / ProcessPrng 等 Win8+ API。
- 主窗口需要 OpenGL 2.0 以上；桌面歌词窗不需要（纯 GDI 绘制）。
- QQ 音乐搜索接口有风控，偶尔拿不到结果，程序会自动退避重试并尝试“按歌名直取”。
- 个别歌曲因区域版权搜不到原唱时，程序会判定“无可信匹配”，不会乱写错误歌词。
